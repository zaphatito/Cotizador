SISTEMA DE COTIZACIONES — REGISTRO DE CAMBIOS
Versión: 2.0.18
Fecha: 2026-07-10

Resumen
- Se corrigió el inicio ocasional sin código de tienda ni usuario, que podía producir códigos de cotización con el identificador 00.

Cambios y mejoras
- [Mejora] Un bloqueo temporal de SQLite ya no hace que la aplicación cambie silenciosamente a otra base de datos.
- [Mejora] Si debe usarse la base de respaldo, la identidad del cotizador se recupera desde la base principal en modo de solo lectura.
- [Mejora] El código completo reservado por el servidor se conserva al guardar, reimprimir o regenerar una cotización.

Correcciones
- [Fix] Se impide generar una cotización cuando falta el código de tienda o el nombre de usuario.
- [Fix] Se rechazan códigos reservados para una tienda diferente, incluido el identificador 00 incorrecto.

Notas importantes
- La actualización no reemplaza ni elimina la base de datos local existente.
- Las cotizaciones antiguas ya guardadas con un código incorrecto no se modifican automáticamente.



Compatibilidad
- No se requieren cambios de esquema para esta versión.
- La base de datos local y la configuración del usuario se conservan.

Soporte
- Si notas algún comportamiento inesperado después de actualizar, reinicia la aplicación y vuelve a intentar.
- Si el problema persiste, llama al soporte técnico.
