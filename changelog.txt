SISTEMA DE COTIZACIONES — REGISTRO DE CAMBIOS
Versión: 2.0.43
Fecha: 2026-09-14

Resumen
- Recuperación de cotizaciones locales pendientes y compatibilidad con números antiguos.

Correcciones
- [Fix] Las cotizaciones recientes sin enviar entran en sincronización antes de completar la incorporación del histórico antiguo.
- [Fix] El envío da prioridad a cotizaciones pendientes y cambios locales, conservando el procesamiento del histórico por lotes cortos.
- [Fix] Al detectar el API 1.6.5 compatible, se reintentan una vez los envíos bloqueados por «Código de cotización inválido», con el mismo número y sin perder cambios posteriores.
- [Fix] El histórico muestra cuántos envíos están pendientes o requieren revisión; una conexión activa ya no oculta esos bloqueos.

Compatibilidad
- Se conservan la configuración, las cotizaciones guardadas y los cambios pendientes.
- La recuperación de códigos antiguos requiere actualizar y reiniciar primero el API 1.6.5. No requiere otra migración SQL.
